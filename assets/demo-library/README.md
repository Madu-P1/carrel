# Carrel Demo Library

These three PDF fixtures are synthetic CC0-1.0 samples generated for Carrel's public beta onboarding flow.

- `carrel-demo-clean-reading.pdf`: clean prose with a normal text layer.
- `carrel-demo-table-heavy.pdf`: compact table-like content for extraction/navigation checks.
- `carrel-demo-ocr-boundary.pdf`: short OCR-boundary prose that explains scanned-document failure modes while remaining readable in local test environments.

The total asset budget is intentionally tiny so the demo library can ship inside the desktop bundle without affecting app size.
