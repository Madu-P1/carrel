# Cachet trademark clearance worksheet

Run this BEFORE filing. It covers two marks and is structured so a non-lawyer can
execute the knockout pass and hand a clean (or flagged) result to an attorney. This
is a screening guide, not legal advice.

## What is being cleared

1. **Word mark:** CACHET (standard characters).
2. **Design mark:** the withheld-strike logo (open ring (the truncated C), severed in the upper-left). Master at
   `macos/cachet-appicon-1024.png`, source `cachet-mark.svg`.

**Classes / goods (intended):**
- **Class 9:** downloadable software for verifying / fact-checking AI-generated
  output; software for source-grounded citation and claim verification.
- **Class 42:** SaaS and PaaS providing AI output verification; non-downloadable
  software for checking the accuracy of AI-generated text and citations.

Tighten the wording against actual product scope before filing; goods/services
language drives the conflict analysis as much as the mark does.

## Preliminary findings (web sweep, 2026-05-31, NOT a clearance)

- No "Cachet" mark found in the AI / verification / legal-tech lane. Existing
  "Cachet" brands sit in unrelated classes: jewelry (Cachet Fine Jewelry),
  stationery (Cachet Stationery), commercial property (Cachet Group), fashion.
- "Cachet" is a laudatory dictionary word (it means prestige / a mark of
  distinction). Expect a possible weakness / descriptiveness angle; the stylized
  design mark and the coined use on software are what give it teeth. Cachet Group
  already markets itself on the "mark of distinction" idea, same etymological well.
- The chosen mark is an open ring (the truncated C), NOT a circle containing a separate C. That distinction matters: a C inside a circle reads as the copyright symbol, while the open-ring form avoids it. A broken/open ring is still a common geometric device, so the reverse-image and design-code steps below are the real test. (An earlier octagon version was dropped.)

These are keyword results. They do NOT clear visual similarity or catch
unregistered/pending marks. Do the formal steps below.

## Formal knockout search (do all four)

### 1. USPTO design-code search (catches registered/pending marks keywords miss)
- Tool: USPTO Trademark Search, `https://tmsearch.uspto.gov` (the post-TESS system).
- Design Search Codes (confirm exact subcodes in the USPTO Design Search Code
  Manual before relying on them):
  - **26.01** Circles, including incomplete circles / a circle with a break (the open ring).
  - **26.01.21** Incomplete circles and circles with a break; confirm the exact subcode in the Manual.
  - If the C reads as a stylized letter forming a device, also **27.03** (letters
    forming designs). A plain letter is otherwise treated as the literal element.
- Query shape: design code (circle / incomplete circle) AND International Class (009 OR 042) AND
  status = LIVE. Review every hit visually.

### 2. Reverse-image search (the step keyword search cannot do)
- Run `macos/cachet-appicon-1024.png` and `cachet-mark.svg` (export a PNG) through:
  Google Lens / Google Images, TinEye, and Bing Visual Search.
- Looking for: any existing open-ring or broken-circle mark in software,
  security, legal, fintech, or certification.

### 3. Word-mark knockout for CACHET
- USPTO search: CACHET (and near phonetic equivalents: CACHE, KACHET, SACHET) in
  Classes 9 and 42, LIVE status. Note any in adjacent tech/data/security goods.
- Flag from prior naming work: KACHET NOIR is a known residual phonetic risk.

### 4. Common-law / market search
- Google web + News, Apple App Store + Google Play, GitHub, Product Hunt,
  Crunchbase, Brandfetch.
- Domains and handles: cachet.ai / getcachet / usecachet / trycachet, plus the
  social handles you intend to use.

## Decision gate (do not file until all true)

- [ ] Design-code search in Classes 9 + 42 returns no confusingly similar LIVE mark.
- [ ] Reverse-image search surfaces no close open-ring / broken-circle mark in a related field.
- [ ] CACHET word knockout in 9 + 42 is clean (or the risk is understood and accepted).
- [ ] Common-law search shows no senior user in the AI/verification space.
- [ ] A trademark attorney (or a paid screening service such as Corsearch /
      Thomson) has reviewed the result. Recommended here: the word is laudatory and
      the filing is pro-se, which raises the value of one professional read.

## Notes for the application

- File the design mark and the word mark as separate applications if budget allows;
  the design mark is the stronger asset given the weakness of the word.
- Keep `cachet-appicon-1024.png` as the specimen-grade image. Filings want a clean,
  high-resolution depiction of the mark as used.
