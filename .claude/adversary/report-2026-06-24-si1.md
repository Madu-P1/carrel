# Cachet Adversary report — SI-1 structural integrity, 2026-06-24

Target: `services/legal/structural_integrity.py`
(`check_cross_references` / `check_structural_integrity`) — the new intra-document,
source-free SI-1 pillar. SI-1 has no "supported / green" state, so the
catastrophic error is the **FALSE LOUD FLAG** (cry wolf on a reference that
actually resolves); a missed dangle is the secondary, less-bad class.

Family attacked: dangling cross-reference (intra-document). Real-contract-shaped
vectors: subsection numbering, leading markup / markdown headings, Roman numerals,
quoted external references, plural ranges/lists, plus resolve/dangle controls.

## Cracks found (all FALSE_FLAG, the costly class) — CLOSED

1. **Subsection vs parent-only declaration.** "Section 4.2" with only Section 4
   declared as a heading -> `flagged 4.2`. HIGH frequency: real contracts
   constantly reference subsections that have no standalone heading. Fix:
   ancestor-prefix resolution (`4.2` resolves if `4` is declared). Locked by
   `test_subsection_reference_resolves_against_parent` (+ deep-subsection and
   no-ancestor-still-flags guards).
2. **Markup / markdown heading.** A heading written "## Section 1" was not
   detected as a declaration -> `flagged 1` (twice: the heading's own anchor and
   the body reference). Fix: strip leading markup (`#>*•-`) before declaration
   matching. Locked by `test_markdown_heading_declaration_is_detected`.
3. **Roman-numeral heading.** "ARTICLE I" declared, referenced as "Article 1"
   (Arabic) -> `flagged 1`. Fix: parse Roman declarations to their Arabic value
   (uppercase-only, so lowercase prose is never mis-parsed). Locked by
   `test_roman_numeral_heading_resolves_arabic_reference`.
4. **Quoted external reference.** A section reference inside a quoted passage
   ("...Section 88 of the Prior Agreement") -> `flagged 88`. It may point at the
   quoted document, not this one. Fix: references within a quote span -> 
   `could_not_check`, never flagged. Locked by
   `test_reference_inside_quote_is_could_not_check`.

## Recall gap (secondary, the less-bad class) — DOCUMENTED, not fixed

- Plural "Sections 7 and 9" is not parsed, so that dangle is missed (silent). The
  contract is that this is a SILENT recall gap, never a false flag. Pinned by
  `test_plural_section_list_is_recall_gap_not_false_flag`. Revisit if plural
  parsing is added.

## Result

After fixes: **0 false flags across the battery**; the true-dangle control still
fires ("Section 12" -> `flagged`). Held-out suite 14/14 green; 368 existing engine
tests unchanged; zero-egress holds (pure functions, no network / DB / model); ruff
clean.

**Headline: SI-1 HELD every adversarial input with zero false flags after closing
4 cry-wolf cracks. The loud `flagged` state now fires only on a confirmed dangle.**

## SI-2 (defined-term-unused) pass — added 2026-06-24

Target: `check_defined_terms`. Costly error class: a false "defined but unused"
flag on a term that IS used. Vectors run: plural use ("Seller" -> "Sellers"),
lowercase use ("Buyer" -> "the buyer"), possessive ("Buyer's"), multi-word terms,
plus a used control and a truly-unused positive.

Result: **0 cracks.** Conservative use-counting (case-insensitive, trailing-s
tolerant) suppressed every false-flag vector; the truly-unused term was still
flagged. HELD on all. Locked by `DefinedTermTests`. Documented limitation (a miss,
not a false flag): a hyphen/space variant of a defined term ("Non-Disclosure" used
as "Non Disclosure") can leave the term counted as unused; low frequency, never a
false accusation.

## SI-3 (internal contradiction) pass — added 2026-06-24

Target: `check_internal_contradictions` (percent-only, reuses the D3 proper-noun
percent subject). Costly error class: a false "the document contradicts itself"
flag from a mis-bound subject.

Vectors run: true same-subject mismatch (S1); different subjects (S2); same value
same subject (S3); broken adjacency "10% to France" (S4); DIFFERENT FACTS near the
same proper noun, "10% France tax" vs "20% France tariff" (S5); money near a proper
noun (S6); sentence-final percents (S7).

Crack found: **S5** flagged as a contradiction when it is two different facts about
France. A bare proper-noun subject cannot separate "two values of one quantity"
from "two quantities near one name". DECISION (ADR-0013-faithful): SI-3 emits
**`could_not_check`**, never `flagged` - it surfaces "possible inconsistency,
review this" without ever accusing. Unlike cross-document D3 (a claim vs an
authoritative source), both intra-document percents are co-equal and may both be
true. After the fix: S1 and S5 both `could_not_check`; S2/S3/S4/S6/S7 silent; money
never compared. Locked by `InternalContradictionTests`, including a safety-invariant
test that SI-3 never emits `flagged`. A confident flag awaits T1 subject-binding.

## Three-reviewer hardening pass + rebuild — added 2026-06-24

After the SI-1/SI-2/SI-3 adversary passes above, an independent THREE-reviewer pass
(/mythos 5 finders, /review Claude adversarial + Codex cross-model, /code-review
high-effort) ran over the whole diff. They CONVERGED on a cry-wolf CLASS the single
adversary pass + 28 tests had missed. Root cause: SI-1 hand-rolled a declaration
parser narrower than `anchors._SECTION`, so every reference form anchors recognized
but the declaration parser did not became a false flag.

Eight confirmed false-flag vectors, all empirically reproduced and now CLOSED:
1. inline / run-in declared section ("...adds Section 10 (Force Majeure)...").
2. bare statute symbol "§ 1988" (the litigator wedge's core input).
3. reference to another agreement ("Section 5 of the Credit Agreement").
4. parenthetical subsection heading "4(a)".
5. parent reference when only subsections are declared.
6. lowercase bare-number heading ("4.2 indemnification").
7. irregular plural defined term (Party/Parties, Company/Companies).
8. plural-defined term used in the singular (Holders/Holder).
Plus: SI-2 O(terms×doc) DoS, and "dead on the wire" (the envelope key is dropped
before the API response — SI-5 surfacing work, intentional staging).

Rebuild (root-cause fix): SI-1 now DERIVES keyworded declarations from the SAME
`extract_anchors` section anchors it uses for references (the two can no longer
diverge); statute / external-agreement / quoted / attachment / fragment refs route
to could-not-check; resolution walks ancestors AND descendants; SI-2 uses single-pass
STEM counting (plurals both directions) with size/term caps for the DoS;
`dataclasses.asdict` serialization; disposition CONSTANTS; SI-3 span covers all
values; the test is registered in the CLAUDE.md verify chain.

**Headline: after the rebuild, a deterministic sweep shows ZERO false flags across
all 12 confirmed vectors with the genuine catch intact; 43 SI tests + a 701-test
engine/verify/zero-egress subset are green.** Lesson logged: a single adversary pass
plus green tests gave false confidence; the multi-reviewer pass is mandatory before
trusting a "hardened" verdict on a cry-wolf-sensitive surface.

## Adversary fan-out (8 fresh-context angles, 124 cases) + second rebuild

After the three-reviewer rebuild, an 8-angle adversary fan-out (cross-ref
numbering, declaration formats, statute citations, external documents, defined-term
morphology, quoted/embedded, whitespace/unicode, SI-3 percent) hit the fixed
engine. It found **14 more cry-wolf cracks** the rebuild still missed (0 crashes, 0
missed catches; the engine HELD on 12 other tricky cases: no-newline paste, CRLF,
NBSP, ZWSP, Arabic-indic digits, bare §). Four classes:

1. External instruments the `of the <Capitalized name> Agreement` regex was too
   strict for: "of the Lease", "of that certain Note", "of the 2019 Plan" (digit
   name), "under the Master Agreement" (connective), "of the credit agreement"
   (lowercase), "of the Deed of Trust". Fixed: broadened connective + determiner +
   any-case/digit name + instrument-noun set; "this" determiner stays internal.
2. Defined-term stemmer mismatch: the blanket `es`-strip turned "Notices" into
   "notic" so it never matched "Notice" (same for Service/Services,
   Affiliate/Affiliates, Index/Indices). Fixed: `es`-strip only on sibilant
   endings + an irregular-plural lexicon (indices/analyses/bases/...).
3. Section references inside SINGLE quotes (straight and smart) were not detected
   (only double quotes were). Fixed: boundary-anchored single + smart-single span
   detection unioned into the quote guard.
4. Full-width / non-ASCII digit references ("Section ５") false-flagged. Fixed:
   NFKC digit folding (so a full-width declaration reconciles with an ASCII
   reference) + a non-ASCII reference routes to could-not-check.

All 14 are now locked by held-out tests (FanoutHardeningTests) and silent in a
deterministic sweep; an internal "of this Agreement" dangle still flags. 48 SI
tests + a 473-test engine/verify/zero-egress subset green, ruff clean. A second
fan-out round is the dry-confirmation gate.

## Fan-out rounds 2-3 + the could-not-check decision

Re-running the fan-out against each fix kept finding cry-wolf on the SI-1 dangling
cross-reference (14 -> 7 -> 1 across rounds 1-3), always on external/qualified
references: instrument named after the number ("of the Lease", "of the
Prospectus"), instrument named before it ("under the Master Agreement, see Section
8"), broadened connectives ("to", "from", "contained in"). Tightening the qualifier
rule then started eroding the genuine catch (benign "Section 9 in all respects" got
suppressed). The conclusion: confidently telling an INTERNAL dangle from a reference
to ANOTHER instrument in free legal prose is a semantic problem a deterministic
regex cannot win, and patching trades cry-wolf for missed-catch indefinitely.

**Decision (Madu, 2026-06-24): SI-1 is COULD_NOT_CHECK-ONLY.** A section reference
that does not resolve to a declared section now surfaces as "review this reference",
never a loud flag. This closes the SI-1 cry-wolf class BY CONSTRUCTION (provably
zero false flags) and let us delete ~80 lines of fragile heuristics. SI-3 is also
could-not-check-only (ADR-0013). Only SI-2 (defined-term-unused) keeps a loud flag,
and it held across all three rounds after the stemmer fix. A final SI-2-focused
adversary round is the remaining gate. Headline: the honest refusal carries SI-1
now; the loud flag lives only where determinism is sound.

## SI-2 rounds 4-5 + FINAL VERDICT

A focused SI-2 adversary round (the only remaining loud-flag surface once SI-1/SI-3
went could-not-check-only) found 11 morphology cry-wolf cracks: multi-word plurals
("Indemnified Parties", "Affiliated Companies", "Market Indices"), irregulars
("People"/"Person", "Children"/"Child"), Latin singular-s ("Basis"/"Bases",
"Analysis"/"Analyses"), hyphenated reuse ("Force-Majeure"), and non-final
possessive ("Buyer's Group"). Unlike SI-1's semantic problem, this was
MORPHOLOGICAL and tractable, so SI-2 was FIXED (not downgraded): single- and
multi-word matching unified on one stemmer via stem-subsequence counting, the Latin
singular-s bug fixed, bidirectional English irregulars added. A re-run SI-2
adversary round (103 cases, 4 fresh angles) returned **0 cry-wolf, 0 crashes -
CONFIRMED CLEAN**.

**FINAL VERDICT: the cry-wolf class is exhausted (14 -> 7 -> 1 -> 11 -> 0 across
five adversary rounds).** SI-1 and SI-3 are could-not-check-only (flag-free by
construction); SI-2's loud flag is adversary-confirmed clean. 56 SI tests + the
comprehensive engine/verify/zero-egress suite green, ruff clean. The deciding
principle: a SEMANTIC ambiguity (internal vs external reference) becomes
could-not-check-only; a MORPHOLOGICAL gap (stemming) is fixed and keeps its flag.
